核心能力 Capabilities

dsh-remote · DeepSeek Harness plugin

连上你维护的 SSH 机器，把远程目录当成真正的 DSH 工作区——Agent 直接在那里读、写、跑、同步。

🖧

多机 SSH

密码 / 私钥 / SSH agent / OTP / 跳板机，可选系统钥匙串加密。

🔗

~/.ssh/config 别名

实时解析

只存别名，每次连接重新解析；改配置即生效，注册表不存副本，并显示别名实际指向哪台机。

🗂️

双 tab 工作区选择器

本机走系统对话框；远程弹窗内浏览+实时补全，Windows 显示多盘视图，确定后创建本地镜像并被 harness 收养。

🔄

三路冲突检测同步

rw_sync / rw_push：两边都改过的文件列为冲突、绝不静默覆盖；支持 dry-run 与后台任务。

@

远程 @ 补全

远程会话列出远端目录树（SFTP 实时读），候选是工作区相对路径，远端不可达时回退本地镜像。

🔐

安全与可追溯

主机指纹 TOFU 校验；每条远程命令写入审计日志；凭据只存本机。

🖥️

远端 DSH 界面挂到本机

0.8.36+

远端不开任何端口：SSH 连过去起一个只监听 127.0.0.1 的 dsh web，再把端口隧道回本机浏览器。

🩺

连不上？体检与部署

0.8.36+

只读体检报出平台 / node / 原生模块能否启动 / 代理与 npm 源；一键装到远端私有目录（不写系统目录、不改 PATH、删目录即回滚）并逐步校验。

↔️

端口转发

本地与反向 SSH 隧道，定义持久化，断开时停止。

✏️

侧栏远程编辑

远程文件 tab 可直接编辑保存（mtime 乐观锁，冲突 409）；文件操作按会话绑定机器。

♻️

自动更新

0.8.24+

默认自动检查并应用新版本；宿主半可在线热切换，更新后无需重启 harness。

🛡️

远端 sandbox

0.8.54+

远端命令以前不受任何策略约束。现在 rw_* 套用与本机相同的已解析模式：read-only 拒写入/命令/转发，workspace-write 把写入围在工作区内，danger-full-access 全放行；拒绝时给出与本地同形状的沙箱错误与升级提示。遏制而非安全边界。

⌨️

内嵌 PTY 终端

0.8.54+

rw_exec 跑一条命令就关，没有 PTY。新的持久 PTY 通道让 vim／top／sudo 提示符都能用；会话归宿主所有，关浏览器不杀远端 shell，空闲 30 分钟回收。

🗂️

主机分组

0.8.54+

environment／location／tags 纯标签，rw_machines 直接筛；筛不到时列出已有分组。机器多了，「选对机器」从记性变成筛选。

🔗

多跳跳板机

0.8.54+

等价 ProxyJump a,b,c：跳板自带 proxy，从最远一跳往里建。凭据不跨跳继承；超 8 跳明确报错，把配置成环变成清晰错误。

🔐

凭据不留明文

0.8.54+

密钥库写入失败时，默认不保存该密码（credentialFallback: refuse），而不是像以前那样静默回退成明文写进 machines.json。
