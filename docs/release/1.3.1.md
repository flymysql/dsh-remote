# 1.3.1 — SSH 连接恢复与代理网络更新

- SSH 在握手完成前断开时，等待 350 ms 后最多重试一次；并发请求共享连接恢复，关闭或切换主机会取消重试。认证失败、主机指纹不匹配与算法协商失败不会重试。
- 更新器读取进程 HTTP(S)_PROXY 与 NO_PROXY；npm 不可达时使用官方稳定 GitHub Release，并在解包前校验资产 SHA-256。保留 npm SRI 校验、原子替换与回滚、自修复加载及 TLS 证书验证。
- 连接错误区分不明原因的握手前断连与算法协商失败。终端 SSH 可用而 native 后端失败时，可在主机高级配置选择系统 OpenSSH；本版不会静默切换后端。

## 安装

```sh
dsh plugin --profile web add dsh-remote@1.3.1
```

重启 DSH Web 并刷新页面。SSH 主机和工作区无需重新创建。旧更新器无法访问 npm 时，需要通过插件管理器先安装本版；新版本的网络修复才会对后续更新生效。

## 验证与范围

修复 PR #185 的 Linux、macOS、Windows 与六组 Agent 验收全部通过；本地全量 1,560 项通过、10 项跳过。真实本地 SSH、HTTP CONNECT 与 TLS 测试覆盖断连恢复、取消、认证不重试、证书拒绝及请求超时。模拟 npm 不可达时，已实际下载官方 1.3.0 资产、校验摘要并安装至临时目录。

1.3.1 标签的 Release 工作流另行执行 Node 22/24 跨平台检查、覆盖率、Agent 验收、安装包检查及上一版升级/回滚验证，全部成功后才发布。Agent 验收中的脚本适配器不等于真实在线模型验收；本次未新增真实在线模型验收。用户提供的公网主机从云端无法建立 TCP 连接，未宣称这些主机已恢复。

## English

One bounded retry recovers transient pre-handshake SSH disconnects. Updates honor process proxy settings and can use SHA-256-verified official stable GitHub assets if npm is unavailable. Integrity failures remain fatal; authentication, host-key verification and crypto policy are unchanged. If system SSH succeeds while the native backend fails, select the existing per-host OpenSSH backend. Restart DSH Web and refresh after installation.
