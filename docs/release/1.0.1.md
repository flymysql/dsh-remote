# 1.0.1 修复版验收

本次修复来自 DSH 0.2.1-rc.5 实际升级反馈：页面复用了旧版本 CSS，“编辑 SSH 配置”仅请求系统打开程序，原生工作区文件入口显示本地镜像，以及运行中开启自动更新没有启动检查。

- Linux 完整回归：1318 项，1309 通过、9 项按环境跳过、0 失败。
- 真实 DSH 0.2.1-rc.5 设置页：预置旧 CSS 后无需刷新恢复布局；内置 SSH 配置读取、保存、外部冲突、工具按钮、手机与桌面、旧宿主图标兼容通过。
- 真实 DSH 0.2.1 / 0.2.2 自动更新：运行中从手动切到自动，由隔离 registry 返回实际候选包，完成下载与真实 Loader 热切换；没有调用手动更新路由，确认只下载一次、运行版本与磁盘一致。兼容 Loader 1.1 的 commit 日志，恢复启用状态后持久化，避免新进程随后被旧禁用写入停止。
- 原生“工作区文件”浏览器入口：列出并打开仅存在远端、没有镜像副本的文件；跨会话、异步返回和卸载保护另有回归测试。
- 真实 Agent 与 SSH/SFTP/GCC 任务：DSH 0.2.0、0.2.1、0.2.2 的脚本模型原生路径，以及 0.2.1 PTC 路径单独验证。完整 CI 与发布矩阵须全部通过后发布。
- 本版未重新宣称公网 SSH、Desktop GUI、Kerberos 和长期弱网压力通过；此前真实模型验收范围见 [1.0.0](1.0.0.md)。

本地覆盖率 84.5%，全局 70% 与每文件 60% 门槛通过。候选包安装后的 11 项行为检查通过；0.8.94 实际更新器升级并回滚通过。最终跨平台矩阵与公开安装结果在发布工作流中验证。
