# 1.6.0 — 提交图、IDE 偏好与一大批健壮性修复

## 新能力

- **远程提交图（#260）**：`GET /dsh-remote/git?action=graph&count=50[&branch=refs/heads/main]` 返回远端仓库的提交历史（`git log` 携带 **parents**（驱动分叉/合并连线）与 **refs**（引用徽章）、`for-each-ref` 分支列表、`symbolic-ref` 当前分支）。只读，复用既有 `runGit` 的取消/超时/容量边界；`branch` 参数只接受 `refs/heads/<word>`（恶意值回退 `--all`，不会到达 git）。better-sidebar 的 Git 页签现在可以显示远程工作区的提交图——本地镜像从不带 `.git`，历史数据只能由插件提供。

- **IDE 模式按钮可见性偏好（#279）**：设置 → 插件偏好新增「显示 IDE 模式按钮」开关（默认开）。隐藏它是**独立偏好**，不影响 `remoteIdeState.enabled`——已经打开的 IDE 会话保持可用，布局选择独立持久化；重新开启恢复按钮。

## 搜索与同步

- **rg 快路径修复（#314）**：`-I` 在 rg 里是 `--no-filename`，此前快路径恒返回无匹配；快路径现在也应用忽略规则。
- 搜索上限填满即视为截断并停走（#303），不再静默漏报；@ 补全按路径的读取错误只影响该次查询，不再触发 30 秒全局熔断退化到镜像（#309）。
- 核心工作区搜索覆盖未同步远端文件（#228/#232/#259）：镜像会话的 `search` 接缝走远端 `rg --files`，空目录不报错、超 maxOutputChars 的截断如实标记、find 回退应用隐藏/排除过滤、effect 生命周期正确。
- `rw_sync`/`rw_push` 遵守 maxFiles 上限（#235），dryRun 不再创建远端目录（#234），上传失败如实报告（#233），批量下载复用镜像边界与符号链接校验（#230），取消后台同步后停止后续传输（#236），`rw_exec` 先检查取消信号再派发命令（#283）。
- 尾斜杠忽略规则只匹配目录（#307），终端环形缓冲按 UTF-8 字节计量（#301，中文输出不再超预算 3 倍）。

## 连接与转发

- 反向转发改听 ssh2 实际发出的 `'tcp connection'` 事件（#223），停止时关闭已建立的反向连接（#269），编辑后按实际绑定端口管理（#287）。
- OpenSSH 断开后回收命令与握手子进程（#285）。
- 并发打开同一台机器的远程界面按机器串行化，不再泄漏本地监听与远端进程（#299）；「停止远端」只在被证实后上报成功（#305）。
- 链路抖动后 Web attach 自驱重连循环（#204），本地端口全程保持绑定；SSH 通道建立往返窗口内连接被重置不再抛出未捕获异常崩宿主（#297）。

## 自更新与注册表

- 自更新回滚尝试每个文件（不在首次失败处中断），并删除新版本不再提供的文件（#311）。
- `machines.json` 与 `known_hosts` 原子写入；损坏文件被隔离可观测，不再静默加载为空（#295/#293）。
- 切换机器时新记录缺少的每机器字段重置为默认，不再继承上一台的 backend/hostKeyMode（#291）。
- ssh 配置的 Match 段被当作块边界，参数不再泄漏进上一个 Host 块（#289）。
- 镜像复用校验机器身份（#277）、镜像绑定校验实际物理根（#273）、工作区清理校验会话归属（#275）。
- webServer 路由登记中途失败时已登记的路由随子 fiber 撤销（#227）。

## 其他

- `rw_connect` 探测超时报成明确超时（带预算与主机），不再是裸 `exit -1`（外部贡献 xue1813，#221）。
- 远端递归删除部分失败如实报告（#271）；保存回滚失败报告备份位置（#267）；侧栏百分号路径查询复用会话/镜像解析（#265）；Desktop 取消 Git 请求后宿主不再执行（#263）；diff 正文行按 hunk 范围识别（#261）。
- per-machine shell 配置全链路生效（#206）；rw_pick_workspace 语义澄清（#205）；「下载到本地镜像」显示落地路径 + 在文件夹中显示（#207）；下载到运行浏览器的那台机器（#209）。
- 工程：release 后置安装验证加 packument 传播重试（#218）；#219/#220 的诊断与缓解落地（#222/#225）。

## 安装

```sh
dsh plugin --profile web add dsh-remote@1.6.0
```

重启 DSH Web 并刷新页面。SSH 主机、镜像与工作区记录无需重建；新能力均为可选（提交图与 IDE 开关开箱即用）。
