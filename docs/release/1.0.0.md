| 覆盖率 | 加权行覆盖 84.4%；整体门禁 70% 与逐文件 60% 通过 |
| 真实 Agent 任务 | 最新 DSH 0.2.2-rc.1：编译失败→修复→构建→运行，以及停止后续写入→同会话继续任务，2 项显式启用后通过 |
| 脚本模型 + 真实 Web | DSH 0.2.0-rc.2、0.2.2-rc.1 原生/PTC 路径；实际 Agent、SSH/SFTP、GCC 和 Chromium，非预制编译输出 |

真实模型首次请求曾因余额不足返回 402；补充余额后重新运行通过。此故障没有记为通过。模型实际出现过“GCC 失败后追加 echo，整条 shell 返回 0”，因此界面在保留真实退出码的同时，独立突出编译错误。

默认回归中的 9 项跳过包括 2 项需完整宿主的 Agent 用例（已单独启用验证）和 7 项外部 SSH / Web / Kerberos 环境用例。回环 SSH 与真实 shell/编译器验证不能替代所有企业网络、认证方式和大目录压力测试。用户提供的公网机器连接未成功，按用户要求停止；没有登录或修改该目标，也没有把它计为通过。

当前云环境没有 macOS Desktop 应用，旧的 `boot-smoke.sh` 桌面路径检查不能运行；真实 Web 启动及完整任务链路另行通过。Desktop GUI、Kerberos 专有认证和长期弱网压力没有在本次冒充已验收。

复现方式见 [testing.md](../testing.md)，发布门禁与渠道见 [PUBLISH.md](../../PUBLISH.md)。截图和会话事件由独立测试输出，自动化 Agent 工作流上传为 Actions artifacts；API key 不写入会话、源码或发布包。
