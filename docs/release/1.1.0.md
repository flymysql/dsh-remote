# 1.1.0 日常开发验收

本版围绕“打开项目 → 找文件 → 编辑 → Agent 构建 → 核对改动”增加 IDE 模式、递归搜索、远端 Git 差异和保存保护。各远程工作区仍独立绑定主机，不引入全局当前远程机。

## 使用方式

- 在远程会话标题区点击 **IDE 模式**，切换为文件树、原生编辑器标签、真实会话三栏。拖动分隔线或聚焦后用方向键调整列宽；Home 或双击恢复默认。返回普通模式不会重建会话和编辑器。
- 文件栏的搜索支持文件及目录名称、仅文件、仅目录和文件内容。默认只显示紧凑进度和结果；**搜索选项**包含大小写、忽略项，**扫描详情**包含真实目录/文件计数、耗时和跳过原因。可以停止、重试、展开目录和打开匹配行。
- 文件栏的 Git 图标打开远端改动面板，分别核对工作区及暂存区差异。只读查看，不自动暂存、提交、丢弃或解决冲突。
- 文件栏不再展示镜像同步状态；原有同步功能与工具保留。

## 能力边界

- IDE 是对宿主现有面板的可逆布局适配，没有复制会话，也不修改已安装宿主源码。当前布局验证面向 DSH Web 0.2.1/0.2.2；宿主 DOM 标记变化可能需要更新适配。不提供语言服务、扩展宿主和远端调试器。
- 草稿保存在页面内存中，切换布局和会话可保留；浏览器崩溃或强制退出仍可能丢失。
- 搜索默认跳过忽略目录、二进制及超大文件，受时间、条目数和结果数上限约束。超限或部分目录失败显示部分结果；取消停止排队和结果发布，不关闭其他功能共享的 SSH 连接。
- Git 面板要求远端 Git 和 POSIX shell；纯 Windows shell 会说明不支持，不伪装成干净仓库。
- revision 是乐观并发检查，不是远端文件系统提供的多写者事务。普通 CRLF 文件会保留；混合换行会明确标记。
- 历史 Agent 记录没有新元数据时，仅显示原有替换片段；未知原文、二进制或超大差异会显示限制，不伪造完整 diff。
- DSH 0.2.0-rc.2 不生成或保存 PTC 子调用的展示元数据，包括编辑 diff 与命令执行元数据；该组合完整执行相同 7 步验收，成功编辑仅显示请求的替换片段，不显示“已应用”标记。0.2.0 原生调用及已验收的 0.2.1-rc.5 / 0.2.2-rc.1 原生与 PTC 调用仍要求真实 diff、上下文和增删行数；不修补旧宿主或向模型消息注入 diff。

差异计算随包携带 jsdiff 8.0.4 的最小 ESM 源码集合与 BSD-3-Clause 许可。没有新增运行期外部依赖，旧更新器无需重新安装依赖即可升级。
