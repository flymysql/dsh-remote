日活 · 运行安装

按北京时间统计当天成功上报的运行安装，同一安装每日去重，包含后台持续运行，并非独立人数或实际操作人数。新版客户端运行期间每 15 分钟检查，成功后当天不再发送；历史旧版可能漏计跨日运行。今天尚未结束，最后一根柱刻意压暗。

npm 下载量对照口径

npm 下载量包含安装、升级、重复下载和自动化流量，不代表新增用户或活跃用户。比较时应看同为 7 天的 WAU；关闭统计、网络失败、旧版漏报，以及 GitHub 安装包等不同安装渠道，都会造成两者差异。心跳与下载数据由定时快照更新，通常每 6 小时刷新，并非实时。
